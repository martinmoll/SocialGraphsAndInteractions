How we work

  • Every week's numbers are recomputed from the frozen course snapshot, which is committed to the repository unmodified so all three of us run on identical bytes.
  • Every post ends with the modelling choices behind it — thresholds, layouts, what we excluded — because a result whose assumptions are hidden is not a result.
  • Notebooks live alongside the posts. If a figure appears here, the code that made it is in the repository.
