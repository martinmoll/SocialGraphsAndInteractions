## Layout

| Path | Contents |
| --- | --- |
| `index.html`, `style.css` | Site homepage and stylesheet, served at the Pages root |
| `posts/week{N}/` | That week's write-up |
| `Figures/Week{N}/` | Exported figures used by that week's post |
| `Notebooks/Week{N}/` | Analysis notebooks, plus `stats.json` |
| `Data/Week{N}/` | Frozen course datasets, exactly as downloaded — never edited |
| `docs/COURSE.md` | Course reference for humans and coding agents |

Every number in a post is read from that week's `stats.json`, and each notebook ends
with a check pinning its headline figures, so the prose cannot drift from the data.
